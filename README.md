# Simple Interest Calculator

## About the Project
The Simple Interest Calculator is a Bash-based application that calculates simple interest using the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Fields
- Principal amount
- Annual rate of interest (percentage)
- Time period (in years)

## Technologies Used
- Bash / Shell Scripting
- Git and GitHub

## How to Run
1. Open a terminal in the project directory.
2. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
3. Run the calculator:
   ```bash
   ./simple-interest.sh
   ```
